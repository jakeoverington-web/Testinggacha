# Testinggacha

Portrait idle auto-battle hero collector for mobile, built in Unity.

- Working rules for Claude and contributors: `CLAUDE.md`
- Design decisions: `docs/design/decisions.md`

## Setup

1. Install Unity Hub and Unity 6.6 (6000.6.x) with Android Build Support (the owner's phone is Android).
2. Open this folder as a project in Unity Hub; Unity generates the rest of the project files.
3. Set the Game view to portrait (1080 × 2340).
